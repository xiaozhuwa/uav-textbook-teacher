# 全书课程地图

## 教材与使用边界

- 教材：Randal W. Beard、Timothy W. McLain，*Small Unmanned Aircraft: Theory and Practice*，所附 PDF 为 2025-10-02 版书稿。
- 结构：14章正文，附录A—I。第1—13章以小型固定翼 MAV 为主线，第14章把框架迁移到多旋翼。
- 核心项目：逐章搭建飞行仿真器，而不是只做纸面题。第14章没有 Design Project，也没有14.9节；不得自行虚构。
- 页码：教学底稿默认写原书印刷页；PDF文件页 = 印刷页 + 8。
- 底稿是中文教学改写，不是逐字翻译。具体公式、图和实施细节仍可回到原PDF核对。

## 一张主线图

任务/航点 → 路径规划 → 路径管理 → 路径跟随 → 自动驾驶仪 → 飞行器动力学 → 传感器 → 状态估计 → 回到各层。

模型主线：物理对象 → 高保真非线性仿真模型 → 配平/线性化/降阶得到设计模型 → 控制与制导设计 → 高保真仿真和实物验证。

## 六个教学模块

| 模块 | 章节 | 核心问题 | 完成后的能力 |
|---|---|---|---|
| 系统与对象建模 | 1—4 | 飞机为什么运动，状态和外力如何表达 | 能搭建坐标一致的六自由度仿真骨架 |
| 控制设计 | 5—6 | 复杂非线性对象怎样变成可设计模型并形成自动驾驶仪 | 能配平、线性化、分析模态并设计串级/TECS/LQR |
| 感知与估计 | 7—8 | 传感器实际测到什么，状态如何由噪声量测恢复 | 能建立量测模型、实现多率EKF并诊断误差 |
| 制导与路径执行 | 9—11 | 已闭合的飞行器怎样跟随直线、圆和航点序列 | 能辨识闭环低阶模型、构造矢量场和路径管理状态机 |
| 规划与视觉 | 12—13 | 如何绕障，以及如何从图像得到目标与制导信息 | 能实现RRT/Dubins-RRT、云台指向、地理定位和基本视觉制导 |
| 多旋翼迁移 | 14 | 同一套自主飞行框架怎样替换平台模型与接口 | 能建立多旋翼模型、混控、串级控制、EKF和时间参数轨迹 |

## 前置知识路由

- 坐标/旋转方向不清：先补第2章与附录A，再进入第3、7、13、14章。
- 姿态数值积分或万向锁：查附录B；不要只反复调积分步长。
- trim/线性化数值问题：查第5章与附录F。
- 连续PID/滤波器转代码：查附录C，再回第6、8、13章。
- 协方差、噪声密度、高斯与EKF符号不清：查附录G、H，再回第7—8章。
- 需要复现固定翼参数：查附录E；这些参数不能用于多旋翼或飞艇。
- 单位换算：查附录I；温度用K、压力用Pa，注意原稿个别文字与表格不一致。

## 教学推进规则

1. 默认按章节顺序系统学习；用户带具体问题来时，按上表只补必要前置。
2. 每章至少保留“心智模型 + 一个公式或结构 + 一个数值/工程例 + 一个诊断问题”。
3. 进入第6章前，确认能区分绝对状态与配平偏差；进入第8章前，确认能区分偏置和白噪声；进入第10章前，确认能区分路径跟随与时间轨迹跟踪；进入第14章前，确认四元数与比力概念。
4. 项目调试优先回到最小测试，不在错误坐标模型上直接叠控制器、滤波器或规划器。
5. 对飞艇和异构集群只做明确标注的迁移扩展：保留架构和方法，重建平台模型、约束与验证。
